# na.odin

Collection of random Odin libraries similar to [na.h](https://github.com/nickav/na).

Includes:

library                                 | latest version | category       | description
----------------------------------------|----------------|----------------|-------------
[**base.odin**](./base.odin)            | 0.01           | base           | Basic helpers and na.h-styled function names for Odin
[**math.odin**](./math.odin)            | 0.04           | math           | Math functions (ported from [na_math.h](https://github.com/nickav/na/blob/main/na_math.h))
[**file_watcher**](./file_watcher)      | 0.01           | utilities      | Cross platform file-watcher for Odin
[**profiler.odin**](./profiler.odin)    | 0.01           | utilities      | Simple CPU-timer based profiler
